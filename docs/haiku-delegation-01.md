extraction and independently checkable hypotheses. The capable lead owns design,
integration, acceptance and final review judgment. Builder-fast/review-fast still
start on Luna Fast. Coordination, architecture and consequential review stay on
Sol with the existing stronger escalation. The Opus design policy and user/
prototype authority remain unchanged. No writing, browser or long-context
capability is promoted for Haiku in production policy.

service, benchmark framework, mandatory cross-family gate or approval gate was
added. OpenRouter allowance/budget and native Codex Fast behavior are retained.

Design work uses `claude-design` when its actual instructions are available,
under the [shared design contract](../plugins/model-router/skills/model-router/references/design-consultation.md#optional-design-skill).
Otherwise the existing design consultant uses its own judgment and supplied
evidence. Do not request pasted text, another session or another agent to obtain
optional instructions. Explicit named-skill requirements remain unmet when the
instructions cannot be obtained. User/prototype authority, Live Wires,
accessibility, functionality, browser checks and tool permissions remain binding.

## Small matched canary

One attempt per model/task, same Sol lead, equivalent identity-free packets and
medium worker effort. Disposable Go/Templ fixtures and the existing router were
used. The existing native benchmark helper supplied an additional identity/JSON
preflight, not one of the matched tasks. No new benchmark framework ships.
Fixed acceptance used source locations, ten independently supplied Go cases and
one planted integer-division defect plus a clean clamp control. Outputs were
assessed without identity fields before joining the result map. The lead knew
the sequential order, so this was not fully blinded or randomized.

| Task | Haiku 5.5 | Luna Fast | Dispatcher wall seconds, Haiku / Luna |
|---|---|---|---|
| A: locate code and explain its template use | Passed | Passed | 16.55 / 15.62 |
| B: bounded Go repair used by Templ | Tests and commit passed | Tests passed; commit blocked by sandbox | 30.11 / 22.98 |
| C: known defect plus clean control | 0 missed, 0 false findings | 0 missed, 0 false findings | 17.73 / 14.52 |

Luna B could not write .git under workspace-write. Its repair passed the lead's
independent tests, but routed completion failed and its partial output was
retained. No second attempt was made. This is an infrastructure gap, not evidence
of inferior repair quality. Haiku required no repair in this tiny sample; Luna
required lead completion of the blocked commit if that fixture were delivered.
The fixtures were not delivered or repaired after scoring.

[Structured evidence](evidence/haiku-delegation-01.json) retains source base,
packet digests, initial fixture heads, fixture/test source, outputs, repairs and
literal private router receipts. It distinguishes successful code from failed
closeout and does not label unavailable execution passing.

Claude's top-level counters across A/B/C report 20 uncached input, 686,601 cache
write, 847,206 cache read and 6,698 output tokens, including 3,421 thinking tokens.
Codex A/C report 176,184 input (139,264 cached) and 707 output (157 reasoning).
B2 counters are unavailable in the failed router receipt. Haiku's exact served
identity was confirmed on A/B/C. Codex requested gpt-6-luna with Fast transmitted;
the native events did not independently confirm served identity or service mode.
The Luna column describes that requested configuration, not confirmed Fast service. Do not add cache reads
to Codex input again or add reasoning to output. These counters and Claude's
per-model counters are different scopes and must not be summed together.

The lead performed packet preparation, fixture setup, acceptance, result
inspection and integration. Dispatcher wall times include availability and
transport overhead. Lead tokens, separate setup/acceptance time and full
completion cost are unavailable. Independent review overhead is retained in its
own evidence, not silently excluded from a claimed cost comparison. Measured
charges are unavailable. Claude's list-price cost is not a subscription charge;
paid extra usage was observed disabled and was not enabled. No account/global
settings changed and no paid API model call was made.

This is a small canary, not a statistically reliable benchmark. It does not prove
cheaper completion, model superiority, strong review judgment, long-context
quality, live browser coverage or general feature ownership. The preliminary
results justify only narrow research eligibility with existing fallbacks.
