Plan: Host-aware cache resolution canary

Overview

Smallest Usable Implementation: replace only the reachable Claude-first asset lookups in active dm-review and Pipeline instructions with the existing Workflow Kernel bundle/asset resolver; extend its existing behavioral fixtures and resolver-consumer validator so both cache directions, both active-host ties, coherent roots, optional skips, and regression mutation are enforced. Bump dm-review and Pipeline patch versions, regenerate derived Codex manifests, and preserve one measured configured-key OpenRouter attempt for this single chunk.

No new abstraction, service, policy layer, cache, broker, receipt family, or synchronization mechanism is proposed. The current consumers are dm-review agent/consolidator/recorder selection and Pipeline cleanup-contract initialization; the reachable harm is silent use of an older compatible cache root; the existing mechanism is Workflow Kernel resolve-plugin-bundle/resolve-plugin-asset, which directly replaces the unsafe loops.
